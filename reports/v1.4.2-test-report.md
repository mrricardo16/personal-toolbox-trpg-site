## 版本定位

本次是 `1.4.x` 补丁更新，没有扩充职业、模组或规则系统。目标是修复已确认的数据错误，并把上一轮计划中的稳定性功能合并进入同一补丁版本。

## 已修复缺陷

### Schema 7 无法重新导入

旧代码导出 Schema 7，却只接受 Schema 1～6。现在导入规则为：

- 接受整数 Schema `1～当前 SCHEMA_VERSION`。
- 拒绝 0、负数、非整数和未来版本。
- v1.4.2 导出的 Schema 8 已完成重新导入校验。

### 威胁时钟字段不一致

旧提示代价写入 `value / resolved`，剧情导演和 AI 协议使用 `current / active`，会出现界面提示已推进但真实状态未推进。

现在统一为：

```text
current
max
active
triggered
resolved
triggeredAt
resolvedAt
```

- `advanceClock`、无进展升级和请求提示统一调用同一推进函数。
- 填满时钟表示 `triggered=true`，触发威胁后果。
- 玩家成功解除威胁才设置 `resolved=true`。
- 旧存档中的 `value` 自动迁移到 `current`。

## 合并的稳定性功能

### 撤销上一轮

- 每次新玩家行动前保存一次内存快照。
- AI 响应正式提交后，顶部显示“撤销上一轮”。
- 回退角色状态、消息、检定、线索、节点、NPC、物品、威胁时钟和上下文。
- 回退后写入系统消息和审计日志，形成新的剧情分支。
- 快照不写入持久存档，页面刷新后不保留撤销能力，避免存档体积翻倍。

### API 协议自检

原“测试连接”升级为：

- 网络、鉴权和模型测试。
- JSON 对象响应测试。
- requestId 回传校验。
- `response_format: json_object` 支持检查。
- 不支持时验证兼容回退。

### 诊断包导出

诊断包包含：

- 版本与 Schema。
- 已脱敏配置。
- 当前阶段和错误信息。
- 当前节点及导航历史。
- 最近消息、检定和日志。
- 上下文预算与 Lore Cards 选择。
- 本地存储占用估算。

默认排除主持秘密、暗骰和原始 AI 回复；用户可主动选择包含。

### 长聊天渲染

- 首次只渲染最近 100 条消息。
- 可每次加载更早 100 条。
- 完整消息仍保存在状态和导出存档中。
- 避免数百条聊天一次性创建全部 DOM。

### 结局界面

普通玩家界面不再直接显示内部枚举 JSON，改为：

- 人员情况。
- 真相掌握。
- 证据强度。
- 威胁状态。
- 调查员状态。

KP 调试模式下仍可查看内部数据。

### 存储管理

存档页新增：

- 当前存档估算大小。
- 本工具 localStorage 总占用。
- 每个槽位大小。
- 当前消息数和审计数。
- 一键清理旧审计日志，只保留最近 300 条。

## 未执行与边界

- 未使用真实 DeepSeek/OpenAI 账户发起计费请求。
- API 协议自检需要用户自己的 Key，并仍受浏览器 CORS 影响。
