# TRPG DM Assistant v1.4.4 测试报告

## 修复范围

- API Key 按主机隔离，存档剥离 API 传输配置。
- 远程 API 强制 HTTPS，仅 localhost 允许 HTTP。
- 外部存档结构限制与 runtime 净化。
- API 响应 200KB 上限。
- 本地确定性 JSON 语法修复。
- 正式协议校验器行为测试。
- 生产构建移除测试接口。
- 永久 GitHub Actions CI。

## 必须通过

1. node trpg-dm-assistant/build/test-security-hardening.js
2. 所有源码和构建脚本 node --check
3. node trpg-dm-assistant/build/build-single-html.js
4. node trpg-dm-assistant/build/verify-single-html.js
5. 连续两次构建 SHA-256 一致
6. git diff --check
7. 仓库内仅保留一个 TRPG 产品 HTML
